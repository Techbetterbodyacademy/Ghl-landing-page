# GHL Landing Page

Better Body Academy landing page, cloned from
[ThelbertD/bba-landing-page](https://github.com/ThelbertD/bba-landing-page).

## Structure

- `index.html` — splitter / pick-your-side landing
- `men.html` + `men.css` + `men.js` — men's program page
- `women.html` + `women.css` + `women.js` — women's program page
- `styles.css` + `script.js` — shared styles & enhancement for `index.html`

## Preview

Image binaries currently load from the upstream BBA repo's raw URLs.
Enable GitHub Pages on this repo (Settings → Pages → Source: this branch
→ root) for a public preview at
`https://techbetterbodyacademy.github.io/ghl-landing-page/`.
